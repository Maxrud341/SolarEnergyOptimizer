# ⚡ Real-Time Microgrid & MQTT Control Subsystem

Модуль работы в реальном времени (**Production Real-Time**) для автономной оптимизации солнечной энергии, арбитража на спотовом рынке OTE ČR и прямого управления инвертором через MQTT.

---

## 📁 Структура папки `real_time/`

```text
real_time/
├── .env                  # Секреты и параметры окружения (создан с рабочими значениями)
├── .env.example          # Шаблон конфигурации окружения
├── config.py             # Центральный файл конфигурации и физических констант системы
├── database.py           # SQLite менеджер (WAL-режим, лимит < 800 МБ FIFO)
├── price_fetcher.py      # Загрузчик спотовых цен OTE ČR на сегодня и завтра (Spotovky.cz API)
├── weather_fetcher.py    # Прогноз погоды и солнечной радиации GHI/DNI (Open-Meteo API)
├── battery_sim.py        # Физическая модель батареи Fox-ESS HV2600 HS 10.4 (10.24 кВт·ч)
├── controller.py         # Диспетчер принятия решений и формирования чешских JSON-команд
├── mqtt_service.py       # Основной рабочий сервис-демон (MQTT + Watchdog + симуляция)
├── visualizer_realtime.py# Живой Streamlit-дашборд с автообновлением и индикатором связи
└── data/
    └── telemetry.db      # База данных SQLite (создаётся автоматически)
```

## 🔑 Внешние API и ключи регистрации

> [!TIP]
> **Регистрация и платные ключи НЕ требуются!**  
> Все используемые сервисы являются **100% бесплатными** и открытыми:
> 1. **Спотовые цены (OTE ČR):** API `api.spotovky.cz/v2` — не требует ключа, CORS разрешен. Возвращает цены на сегодня и завтра.
> 2. **Погода и Солнце (Open-Meteo):** API `api.open-meteo.com/v1/forecast` — не требует ключа, неограниченные запросы для личного использования.
> 3. **Брокер MQTT:** `cassandra2.tul.cz:1883` — анонимный доступ по умолчанию. Если на брокере включат авторизацию, логин и пароль указываются в `.env`.

## 🚀 Инструкция по запуску

### 1. Запуск сервиса в боевом режиме (Live MQTT)
Слушает топик `FVE/Maly_TX` на брокере `cassandra2.tul.cz`, пересчитывает симуляцию батареи, пишет в SQLite и отправляет чешские команды в `FVE/Maly_RX`:
```bash
python -m real_time.mqtt_service
```

### 2. Запуск сервиса в тестовом режиме (`--mock`)
Если брокер недоступен или вы хотите протестировать весь пайплайн локально:
```bash
# Генерирует реалистичные 2-минутные пакеты каждые 2 секунды
python -m real_time.mqtt_service --mock --mock-interval 2.0
```

### 3. Запуск веб-дашборда в реальном времени
Открывает интерактивный веб-интерфейс в браузере:
```bash
python real_time/visualizer_realtime.py
# или
streamlit run real_time/visualizer_realtime.py
```

## 🛡️ Отказоустойчивость и безопасность (Watchdog & Jitter)

1. **Джиттер времени:** расчет энергии ведется по реальной динамической дельте $\Delta t = t_{now} - t_{prev}$, сохраняя 100% физическую точность при любых задержках пакетов.
2. **Сторожевой таймер (Watchdog):** если данные не приходят более **5.5 минут (330 секунд)**, сервис:
   * Отправляет инвертору команду безопасности: `"Pokrytí spotřeby domu"` (штатный автономный режим).
   * Автоматически перезапускает сетевое соединение с брокером.
   * Фиксирует событие в базе SQLite.
3. **Восстановление после сбоя:** при появлении свежих данных после длительного перерыва пакеты старше 5 минут отбрасываются, а симулированный SoC калибруется по реальному физическому значению из первого свежего сообщения.
4. **Индикатор связи в веб-интерфейсе:**
   * 🟢 **ONLINE** — данные поступают стабильно (< 2.5 мин).
   * 🟡 **ZPOŽDĚNÍ** — задержка между пакетами (2.5 – 5.5 мин).
   * 🔴 **OFFLINE** — данных нет > 5.5 мин, активен безопасный режим Failsafe.
