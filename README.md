# SolarEnergyOptimizer

Интеллектуальная система управления микросетью (**Microgrid B2G Arbitrage EMS**) для частного дома с солнечной электростанцией (СЭС) и накопителем электроэнергии (АКБ 10 кВт⋅ч) в Чехии. Система оптимизирует работу СЭС в условиях почасового биржевого спотового тарифа (OTE Day-Ahead Market) и пофазного чешского учета (Fázové měření).

---

## Быстрый старт

### 1. Интерактивный веб-дашборд
Запуск современного веб-интерфейса (Streamlit + Plotly) с показом графиков мощности, спотовых цен, финансового баланса и суточных KPI:
```bash
streamlit run visualizer_web.py
```

### 2. Запуск оптимизатора
Основной запуск закрытого цикла симуляции коммерческого арбитража:
```bash
# Актуальная коммерческая модель арбитража (Battery-to-Grid MPC):
python main.py

# Или с явными параметрами:
python -m src.optimizer_arbitrage --output trading_log_arbitrage.csv

# Запуск базовых версий для сравнения:
python main.py --version v2  # Базовая модель самопотребления
python main.py --version v3  # Модель V3
```

### 3. Запуск тестов
```bash
pytest
```

### 4. Генерация сравнительного помесячного бенчмарка
```bash
python scripts/run_arbitrage_benchmark.py
```

## Ключевые особенности алгоритма Arbitrage B2G

1. **Коммерческий экспорт (Battery-to-Grid):** Разрешение разряда аккумулятора в сеть на полной мощности инвертора (до 3.6 кВт) во время экстремальных ценовых спайков спотового рынка.
2. **Защита от паразитного сброса (Real-Time Zero-Export Clamping):** Вне периодов коммерческого экспорта инвертор прижимает отдачу ровно к текущей нагрузке дома. Энергия не вытекает в сеть при ошибках ML-прогноза, а сохраняется в батарее на следующие сутки.
3. **Барьер себестоимости хранения (WACSE Hurdle Rate):** Экспорт из батареи разрешен только если цена продажи покрывает динамическую себестоимость закупки энергии в батарею с учетом КПД разряда (90%) и деградации аккумулятора (0.25 CZK/кВт⋅ч).
4. **Пофазный чешский учет (Fázové měření):** Честный расчет сальдо раздельно по фазам L1, L2, L3 без идеализированного суммирования.
5. **Динамический Zero-Export:** Автоматическое ограничение сброса излишков СЭС при отрицательных ценах продажи.
